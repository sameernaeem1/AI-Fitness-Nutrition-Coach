# AI Powered Fitness Coach
An intelligent, full-stack web application that generates personalised 4-week workout plans. The app takes into account available equipment, current injuries and user goals to generate tailoired plans or provide exercise alternatives. This is more effective than using a generic AI chatbot as it forces structured input and remembers important context such as injuries or long-term goals, which can be changed at any time if needed. Also, the calendar makes the interface user-friendly, allowing you to easily visualise scheduled and previous workout days.
## Features
- User onboarding collects age, gender, height, weight, goal, frequency, injuries and available equipment.
- AI engine generates a 4-week tailored plan based on this information.
- Smart swap feature uses agentic AI to replace any exercise from a workout with a biomechanically equivalent movement.
- Interactive workout calendar allows user to view daily schdules including sets, reps, suggested weights and rest periods.
- Persistent and easy to update user profiles.
